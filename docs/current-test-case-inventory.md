作成日: 2026-07-10

実行結果: [`current-test-execution-report-20260710.md`](./current-test-execution-report-20260710.md)

## 1. この一覧の使い方

- `P0`: 個人情報、認証、権限、RLS、データ破壊、主要導線に関わる最優先ケース
- `P1`: リリース受け入れに必要な主要機能ケース
- `P2`: 異常系、表示品質、運用上重要なケース
- `P3`: 互換性、使いやすさ、改善品質のケース
- 結果は `未実施 / OK / NG / 保留 / 対象外` で記録する。
- `mailto:` の成功は「メールアプリ起動まで」とし、実送信・到達は判定しない。

## 2. 先に決めるべき仕様差分

| ID | 論点 | 仕様書 | 現行実装 |
| --- | --- | --- | --- |
| GAP-01 | 未ログインの企業詳細 | 企業詳細・求人の一部を閲覧可能 | `/companies` の詳細リンクから学生ログインへ誘導し、詳細ルートもログイン必須 |
| GAP-02 | 求人詳細閲覧 | 未ログインでも一部閲覧可能 | 学生プロフィール紐づけ済みログインが必要 |
| GAP-03 | 学生ログイン状態 | `active` がログイン設定済み | 連絡処理は `invited` と `active` の両方を許可 |
| GAP-04 | プロフィール確認日時 | 本人確認日時を保持 | 表示はあるが、学生が確認済みにする操作はない |
| GAP-05 | 共有同意日時 | `profile_share_consent_at` を保持 | 履歴の `consent_at` は保存するが学生レコード側は更新しない |
| GAP-06 | 求人掲載期間 | 開始日・終了日を管理 | 公開画面は `published_at` / `closed_at` による期間判定をせず、状態だけで表示 |
| GAP-07 | 本番DB権限 | 内部列を非公開にする | 2026-07-07報告では権限強化migrationが本番未適用。現状の再確認が必要 |
| GAP-08 | 協賛企業表示 | 実在ロゴ以外を本番表示しない | `sponsors_list.html` に仮企業名・仮ロゴ表現が残る |

# Kinsei company access links

企業登録・再発行時はメールを送らず、管理画面でログイン設定リンクを発行します。

## Flow

1. 管理画面で企業を登録、または企業詳細からリンクを再発行
2. Supabase Admin APIでログイン設定リンクを生成
3. 管理画面に `https://www.kinsei-inc.com/auth/confirm` の自社ドメインURLを表示
4. 運営担当者がリンク、またはチャット用メッセージをコピー
5. 既存のチャット・契約連絡スレッドで企業担当者へ送信
6. 企業担当者がリンクを開き、`/password-update` でパスワードを設定

## Notes

- メール送信サービスは不要です。
- リンクはDBに保存しません。
- 発行直後の管理画面に一時表示し、15分後に表示用cookieが消えます。
- リンクが切れた場合は、企業詳細画面から再発行してください。

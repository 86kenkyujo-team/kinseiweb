# TOPページ刷新 要件定義・モック方針

作成日: 2026-05-18

## 1. 今回の目的

既存 TOP を、理念中心の団体紹介から「実績で学生と企業をつなぐキャリアプラットフォーム」として見えるページへ刷新する。

今回は実装しない。要件定義、デザイン方針、完成イメージの確認用モック作成までを対象とする。

## 2. 参考画像から取り入れる方向性

- 青白い SaaS / AI 風の明るい世界観
- グラスモーフィズムのカード
- K ロゴまたは AI / データリングを中心にした先進感
- 人物写真とデータカードの組み合わせ
- 検索バー、タグ、統計カードによるプロダクト感
- 企業ロゴ、運営メンバー、最終 CTA、濃紺フッターによる信頼感

## 3. 既存 TOP から残す情報

- ブランド名: 近世 KINSEI
- 中核コピー: 学歴ではなく、実歴で戦え。
- 補助メッセージ: なんとなく就活を終わらせる
- 近畿大学起点のストーリー
- 3本柱:
  - マインドセット教育
  - 学生の可視化
  - 採用マッチング
- 価値提供:
  - 学生: 思考・価値観の言語化、実務経験、市場価値の可視化
  - 企業: 価値観把握、ミスマッチ削減、志望度向上
  - 大学: 実務経験を持つ学生輩出、ブランド価値向上
  - 社会: 人材の最適配置
- 実績数値:
  - 登録学生 300名+
  - 参画企業 50社+
- 導線:
  - 学生データベース
  - スポンサー・導入プラン
  - お問い合わせ
- 運営メンバー:
  - 片山 諒
  - 北嶋 元勝

## 4. 現行 TOP の主な課題

- 誰向けの TOP かがやや分散している
- ファーストビューの訴求は強いが、提供機能への接続が弱い
- LINE、フォーム、SNS など一部 CTA が `#` のまま
- 協賛企業ロゴが仮表示で信頼感を出し切れていない
- 外部 Unsplash 画像が汎用的で、KINSEI 固有の実在感が弱い
- カード、影、丸み、グラデーションが多く、ややテンプレート感がある

## 5. 推奨ページ構成

### 5.1 Header

- KINSEI ロゴ
- ナビ:
  - サービス
  - 仕組み
  - 実績・事例
  - メンバー
  - 企業の方へ
- CTA:
  - ログイン
  - 無料で始める / お問い合わせ

### 5.2 Hero

目的: 何のページか、誰に向けているか、何をすればよいかを最初に伝える。

要素:
- コピー: 学歴より、未来をつくる実績を。
- メイン見出し: 実績で戦う。次のキャリアへ。
- 説明: 学生の挑戦と実績を可視化し、企業との最適な出会いをつくるキャリアプラットフォーム。
- 主要 CTA:
  - 学生データベースを見る
  - 企業向け資料を見る
- 右側ビジュアル:
  - K ロゴ
  - 人物写真
  - 浮遊する実績カード / スキル分析カード / マッチングカード

### 5.3 Search / Discovery

- 探索バー:
  - 「スキル・分野を選択」
  - 「キーワードで検索」
  - 「探す」
- 人気キーワード:
  - 長期インターン
  - SNS運用
  - データ分析
  - PdM
  - マーケティング

実検索が未実装の場合、ボタンは実運用の公開学生 DB である `/students` へリンクする。

### 5.4 Metrics

候補:
- 登録学生数 300名+
- 提携・参画企業数 50社+
- 掲載プロジェクト数
- 面談・採用接点数

注意:
実数が未確定のものはモック内では「仮」と明示し、本番では実数に差し替える。

### 5.5 Audience Switch

- 学生の方へ: 実績をつくり、可能性を広げる
- 企業の方へ: 未来の即戦力と出会う

TOP 上ではタブ風に見せ、詳細導線は各 CTA に逃がす。

### 5.6 Reasons / Features

4カード:
- 実績を見える化
- 最適なマッチング
- 成長を支援する仕組み
- 信頼できるネットワーク

### 5.7 Steps

3ステップ:
1. プロフィール登録
2. 実績をつくる
3. 企業と出会う

### 5.8 Partners

- 実ロゴが使用可能な場合のみ掲載
- 未許諾・未確定なら仮ロゴの実装は避ける
- 「協賛企業一覧」への導線は維持

### 5.9 Members

- 片山 諒
- 北嶋 元勝

既存写真を使用する。無機質な AI 風 UI に対して、人の顔で信頼感を補う。

### 5.10 Final CTA

- 見出し: まずは相談してみませんか？
- CTA:
  - LINEで相談する
  - メールで問い合わせる
  - 学生DBを見る

本番実装時は `#` を残さない。

### 5.11 Footer

- 濃紺背景
- ロゴ
- サービスリンク
- 企業向けリンク
- 会社情報
- お問い合わせ

## 6. 実装可能な表現

静的 HTML + Tailwind CDN でも実装可能:
- 青白い背景
- グラスカード
- K ロゴ背景
- 円形データリング
- 浮遊カード
- 統計カード
- 検索バー風 UI
- ロゴグリッド
- メンバーカード
- 濃紺フッター

追加ライブラリなしでも可能。ただし複雑なリングアニメーションやリアルな 3D 表現は避ける。

## 7. レスポンシブ要件

- 390px 前後のスマホ表示を優先確認する
- PC の浮遊カードはスマホで非表示または縦並びにする
- ヒーローの人物・Kロゴ・カードが見出しを邪魔しないこと
- 検索バーはスマホで縦積みにする
- 統計カードは PC 4列、スマホ 2列または 1列
- CTA は常に押しやすいサイズを保つ

## 8. 本番実装前に決めること

- TOP の主対象を学生寄りにするか、企業寄りにするか、両面型にするか
- 実績数値の最新・正確な値
- 企業ロゴ掲載の可否
- LINE / メール / フォーム / ログインの実リンク
- ヒーローに使う人物写真の権利と選定
- 学生DBのリンク先は Next.js `/students` に寄せる。静的 `students.html` は旧デモとして扱う。
